# 교실의 소리, 세계로

유정준 교사의 「26년 교사 글로벌 연수 대상자 선발 지원서_(제출편집).hwpx」를 웹용 교육 포트폴리오로 재구성한 정적 웹사이트입니다. KERIS 디자인 분석의 청색·녹색 팔레트, 큰 제목, 카드, 넓은 여백을 적용했습니다. KERIS 공식 사이트나 로고를 복제한 것은 아닙니다.

## 바로 보기

`index.html`을 브라우저로 열면 됩니다. 빌드, 패키지 설치, API 키, 서버 설정이 필요하지 않습니다. HTML·CSS·JavaScript와 SVG가 모두 같은 폴더에 들어 있어 오프라인에서도 작동합니다.

## 파일 구성

```text
index.html       페이지 콘텐츠와 지원서 원문 문단
styles.css       PC·모바일·인쇄 스타일
script.js        모바일 메뉴·문단 펼침·인쇄·읽기 진행률
assets/          대표 일러스트, 문단별 SVG, 파비콘
content-map.json 원문 문단 번호 ↔ 제목 ↔ 일러스트 대응표
.nojekyll        정적 파일을 그대로 제공하도록 하는 빈 파일
README.md        사용·수정·GitHub Pages 배포 안내
```

## GitHub Pages에 올리기

1. GitHub에서 이 웹페이지용 저장소를 만듭니다.
2. 이 폴더 안의 파일과 `assets` 폴더를 저장소 최상위에 올립니다. 저장소 첫 화면에 `index.html`이 보여야 합니다. ZIP 파일 자체를 올리거나 상위 폴더로 한 번 더 감싸지 않습니다.
3. 저장소의 **Settings → Pages**에서 배포 원본을 **Deploy from a branch**, 브랜치를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다.
4. 배포가 끝나면 Pages 설정에 표시되는 URL을 엽니다. 일반 프로젝트 저장소는 `https://사용자명.github.io/저장소명/` 형태입니다. 메뉴 이름은 GitHub UI에 따라 달라질 수 있습니다.

Git이 익숙하다면 이 폴더에서 저장소를 초기화한 뒤 생성한 저장소의 주소로 push해도 됩니다. 모든 리소스 경로가 상대 경로라 프로젝트 저장소의 하위 경로에서도 작동합니다. 이 패키지에는 자동 배포 워크플로가 필요하지 않습니다.

## 콘텐츠와 일러스트 수정

- 문단 제목·요약·원문: `index.html`에서 해당 텍스트를 찾아 수정합니다.
- 문단 일러스트: 해당 카드의 `assets/p숫자.svg`를 수정하거나 같은 파일명으로 교체합니다. 연결 관계는 `content-map.json`에서 확인할 수 있습니다.
- 색상: `styles.css` 상단 `:root`의 색상 변수를 수정합니다.
- 글꼴: `NanumSquareNeo`를 우선 지정하며, 설치되어 있지 않으면 맑은 고딕 등 시스템 한글 글꼴을 사용합니다. 외부 폰트 서버에 의존하지 않습니다. 분석 대상과 완전히 같은 글꼴이 필요하면 사용 권한을 확인한 웹폰트를 추가하고 `@font-face`를 선언합니다.
- SVG는 직접 작성한 벡터 일러스트입니다. 그래프형 장면은 개념 일러스트이며, 축척이 있는 통계 차트가 아닙니다. 숫자의 정확한 의미는 요약과 원문을 기준으로 읽습니다.

## 원문 반영 기준

- 지원서 본문 5개 영역을 유지하고 각 실질 문단에 요약과 SVG를 1:1로 연결했습니다. 원문은 각 카드의 ‘지원서 문단 읽기’에서 확인합니다.
- 첫 화면에는 영역별 대표 카드 3개가 표시됩니다. ‘세부 활동과 문단별 일러스트’ 또는 ‘모든 문단 펼치기’를 누르면 나머지 항목을 볼 수 있습니다.
- 헤더·제목·인적사항 표는 문단별 일러스트 대상에서 제외했습니다. 이름·학교는 소개에 사용했고 휴대전화와 이메일은 HTML·메타데이터·배포 패키지에서 제외했습니다. 원본 HWPX도 배포 파일에 포함하지 않았습니다.
- 수치·기관명·활동 내용은 제공된 지원서를 기준으로 옮겼습니다. 사실을 독립 검증하거나 수정한 자료는 아닙니다. 2027년 내용은 계획이며 연구대회 심사 중, 전문과정 참여 중, 2차 공개수업 예정 상태를 구분했습니다.
- 본문 요약, 소개 문구, 그림 설명은 웹용 편집입니다. 원문 세부 내용은 펼침 영역에 보존했습니다.

## 사용 기능

- 반응형 메뉴: 모바일 메뉴 버튼, Escape 닫기, 링크 이동 후 닫기.
- 문단 펼치기: 개별 문단·세부 활동·전체 펼침.
- 문단 주소: `#paragraph-43`처럼 특정 문단으로 바로 이동하며 상위 접힘 영역도 열립니다.
- 인쇄/PDF: PC 헤더의 버튼 또는 브라우저 인쇄 기능. 인쇄 시 모든 문단을 열고 종료 후 원래 상태로 복원합니다.
- 접근성: 본문 바로가기, 키보드 포커스, 의미 있는 이미지 설명, 동작 줄이기 설정 반영.

## 로컬 서버로 확인하기 (선택)

Python이 있다면 이 폴더에서 `python -m http.server 8765`를 실행하고 브라우저에서 `http://localhost:8765`를 엽니다. 종료는 실행 창에서 Ctrl+C입니다.
